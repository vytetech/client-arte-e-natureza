# Manual do Site — Atelier Daniel Detomi

Documentação de uso do site e painel administrativo.

## Acesso

O site deve ser acessado pelo endereço oficial configurado para o Atelier Daniel Detomi.

O acesso administrativo é feito pela rota:

```text
/login
```

Use o nome de usuário e a senha cadastrados para a sua conta administrativa.

Recomendações:

- Não compartilhe sua senha.
- Use uma senha individual e segura.
- Solicite a criação de um novo usuário para cada pessoa autorizada a administrar o site.
- Caso suspeite de acesso indevido, troque a senha e desative usuários que não devem mais ter acesso.

## Painel Administrativo

Após o login, o painel administrativo permite gerenciar o conteúdo principal do site.

Áreas disponíveis:

- Obras
- Imagens
- Textos
- Design
- Seções
- Idiomas
- Cupom
- Promoções
- Entrega
- Espaço de Café
- Usuários

As alterações feitas no painel são salvas no ambiente de produção e passam a refletir no site conforme a configuração de cada seção.

## Obras

Na área de obras, o administrador pode:

- Criar uma nova obra.
- Editar título, categoria, técnica, ano, preço e descrição.
- Alterar o status da obra.
- Definir ou trocar a imagem.
- Ativar ou ocultar cupom para uma obra específica.
- Reordenar obras.
- Remover obras quando necessário.

Ao alterar preço, imagem ou status, revise a página pública para confirmar se a obra está aparecendo corretamente.

## Imagens

A área de imagens permite gerenciar arquivos usados pelo site.

Boas práticas:

- Use imagens com boa qualidade.
- Evite arquivos desnecessariamente pesados.
- Nomeie os arquivos de forma clara antes do envio.
- Após trocar uma imagem, confira a visualização no site público.

## Textos E Configurações

Textos institucionais, descrições e configurações visuais podem ser atualizados pelo painel.

Essas alterações não exigem modificação do código-fonte, desde que sejam mudanças de conteúdo ou configuração já previstas no painel.

Mudanças estruturais, novas seções ou novas funcionalidades devem ser avaliadas tecnicamente antes da execução.

## Idiomas

O site possui suporte a múltiplos idiomas.

Pelo painel, é possível habilitar ou desabilitar idiomas disponíveis para o público.

Antes de ativar um idioma, revise o conteúdo correspondente para garantir consistência e qualidade.

## Cupom

A área de cupom permite configurar:

- Ativação do cupom.
- Nome do cupom.
- Percentual de desconto.
- Data inicial.
- Data final.

O cupom só aparece publicamente quando estiver ativo, dentro do período configurado e habilitado para a obra correspondente.

Desativar o cupom não apaga os dados preenchidos.

## Promoções

A área de promoções permite configurar:

- Valor mínimo de compra.
- Ativação dos prêmios.
- Exibição de informações promocionais no site.

Prêmios inativos não aparecem publicamente.

Revise sempre as condições comerciais antes de ativar uma promoção.

## Espaço De Café

O Espaço de Café permite cadastrar e organizar conteúdos editoriais relacionados ao cotidiano do ateliê, como textos, imagens e vídeos.

O administrador pode:

- Criar rascunhos de texto, foto ou vídeo.
- Editar título, conteúdo principal e descrição pública.
- Cadastrar traduções em português, inglês, espanhol e árabe.
- Publicar ou despublicar cada item.
- Remover itens.
- Controlar a ativação geral da área.

Regras importantes:

- Rascunhos não aparecem no site público.
- Itens publicados aparecem somente quando o Espaço de Café estiver ativo.
- A descrição pública aparece no site abaixo do título quando preenchida.
- A anotação interna é exclusiva do painel e nunca aparece publicamente.
- Se um idioma estiver ativo, revise título, conteúdo e descrição antes de publicar.

## Usuários

Administradores autorizados podem gerenciar outros usuários administrativos.

Operações disponíveis:

- Criar novo usuário.
- Editar nome e usuário.
- Redefinir senha.
- Ativar ou desativar usuário.
- Remover usuário quando necessário.

Recomendações:

- Cada pessoa deve usar sua própria conta.
- Evite compartilhar credenciais entre usuários.
- Desative contas de pessoas que não precisam mais acessar o painel.
- Use senhas fortes e atualize-as quando houver suspeita de acesso indevido.

## Segurança

Para manter o painel seguro:

- Não compartilhe senhas.
- Não envie credenciais por canais públicos.
- Use senhas individuais.
- Desative usuários sem necessidade de acesso.
- Troque a senha quando houver suspeita de acesso indevido.
- Mantenha acesso administrativo apenas para pessoas autorizadas.

## Domínio E Hospedagem

O site está hospedado em infraestrutura em nuvem e vinculado ao domínio oficial.

Alterações de domínio, hospedagem, e-mail, certificados ou infraestrutura devem ser realizadas por profissional responsável pelo projeto.

## Suporte E Alterações Técnicas

Alterações estruturais, novas funcionalidades ou intervenções técnicas na infraestrutura devem ser realizadas por profissional responsável pelo projeto.

Mudanças simples de conteúdo devem ser feitas pelo painel administrativo sempre que possível.
